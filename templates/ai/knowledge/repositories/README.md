# Repository Guides

project facts, not framework facts.

Use the knowledge-bootstrap workflow in a real workspace to create drafts whose
keys match `.specify/workspace.yml`. Keep those drafts at `authority: generated`
until a human verifies ownership, build commands, and validation evidence.
